# QueryForge — Defect Register (live)

Established during Phase A baseline. Each row is backed by real execution evidence,
not by the historical `docs/renovation/GAP_ANALYSIS.md` (which is stale — see note).

**Baseline facts (verified 2026-10-31):**
- Backend `runmvn.bat -B -ntp clean verify` → BUILD SUCCESS, **143 tests, 0 failures, 0 errors, 0 skipped** (incl. real `postgres:17` via Testcontainers). Evidence: `.audit/verify_run4.log`.
- Frontend `npm test` → **23 tests across 6 files, 0 failures**; `npm run build` → BUILD_OK, 351.99 kB initial (96.52 kB transfer).
- Authenticated local Compose stack (db, backend `local-auth`, frontend, keycloak, mailpit, prometheus, alertmanager) was already running; backend profile confirmed `local-auth`.
- Real-stack Playwright acceptance: **9/9** against nginx + Spring Boot + PostgreSQL + Keycloak + k6. Evidence: `.audit/e2e_real_stack_run7_final.log`.

| QF-DEF-05 | Run detail live updates | Critical | The backend emits **named** SSE events (`state`, `log`, `artifact`, `error`), but the client used `onmessage`/`EventSource.onmessage`, which only fires for unnamed events. | QF-DEF-06 | Benchmark duration units | High | Template `DUR` is declared in seconds, but k6 reads a bare number as milliseconds. `DUR=10` became `10ms` and k6 rejected the scenario: `duration must be at least 1s, but is 10ms`. | Latest run `stderr.log` contained that exact k6 configuration error; the run failed before any request. | `K6RunnerAdapter.k6Environment` appends `s` for bare numeric duration fields and leaves explicit k6 forms (`60s`, `2m`) untouched. | QF-DEF-07 | Benchmark runner under `local-auth` | Critical | k6 executes inside the backend container with no OIDC session. ## Note on the historical gap analysis
`docs/renovation/GAP_ANALYSIS.md` (2026-10-29) reports many "critical gaps" that are
**already implemented** in the current code and covered by the passing suite:
`/api/experiments` catalog controller, SSE endpoint + `RunEventBus`, `RunManifest` with full
environment fingerprint/checksums/versions, bounded 1 MiB separate stdout/stderr capture,
`activeRuns` terminal-state cleanup, restart recovery, Jakarta-style parameter validation with
field-level errors, Testcontainers PostgreSQL integration test, plan-explorer/theme/skeleton
frontend components, actuator/Prometheus exposure. These were verified present by reading the
sources and by the 143-test green run. The gap analysis is historical evidence only.
