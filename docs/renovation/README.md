## How to Use This Plan

1. Every deliverable in this plan has an ID and acceptance criteria.
2. Nothing is done until its acceptance criteria are met and the evidence is recorded.
3. If a deliverable is blocked, it is blocked explicitly — not skipped or merged into another.
4. The plan is not a wishlist. Each line is either implemented or explicitly deferred with a reason.
